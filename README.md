# AutoDiag AI PRO

Демо full-stack AI-сервиса для **первичной диагностики автомобиля** по симптомам и OBD-II кодам.

## Портфолио-подача (что это за кейс)

**Проблема:** пользователю сложно быстро понять, с чего начать диагностику автомобиля по описанию симптомов.

**Решение:** веб-интерфейс собирает данные по авто и симптомам, backend валидирует ввод и запрашивает OpenAI, после чего возвращает структурированный отчёт с вероятными причинами и шагами проверки.

**Что показывает этот проект в портфолио:**
- практическую интеграцию Frontend + Backend + AI API
- аккуратную обработку пользовательского ввода и ошибок
- работу с REST endpoint'ами и JSON-контрактом
- прикладной сценарий, который легко объяснить на интервью

## Основные возможности

- ввод марки, модели, года, типа двигателя и трансмиссии
- ввод симптомов и OBD-II кодов ошибок
- backend-валидация входящих данных
- AI-генерация диагностического заключения
- светлая и тёмная тема
- экспорт результата в PDF
- health-check endpoint (`GET /health`)

## Быстрый локальный запуск

### 1) Установить зависимости backend

```bash
cd backend
npm install
```

### 2) Создать `backend/.env`

```env
OPENAI_API_KEY=your_openai_api_key
PORT=3000
```

### 3) Запустить backend

```bash
npm run dev
```

По умолчанию backend поднимется на `http://localhost:3000`.

### 4) Открыть frontend

Открой `index.html` в браузере (или через Live Server).

> По умолчанию frontend работает с `http://localhost:3000` при открытии файла напрямую (`file://`).
> Если frontend запущен с веб-сервера на том же домене, используются относительные API-пути.

## Smoke-check (1–2 минуты после запуска)

1. Убедись, что backend жив:
   - открой `http://localhost:3000/health`
   - ожидаемый ответ: `{ "ok": true }`
2. Открой frontend и заполни минимум:
   - `brand` (например, Toyota)
   - `symptoms` (например, «Плавают обороты»)
3. Нажми «Сгенерировать» и проверь, что появился текст диагноза.
4. Нажми «Скачать PDF» и проверь, что файл `diagnostic-report.pdf` скачивается.

## API

### `GET /health`
Проверка, что backend работает.

Пример ответа:

```json
{ "ok": true }
```

### `POST /api/diagnose`
Генерация AI-диагностики автомобиля.

Пример тела запроса:

```json
{
  "brand": "Toyota",
  "model": "Camry",
  "year": 2018,
  "engine": "Бензин",
  "trans": "АКПП",
  "symptoms": "Плавают обороты, вибрация на холостом ходу",
  "errors": "P0171, P0420"
}
```

Пример ответа:

```json
{
  "success": true,
  "diagnosis": "..."
}
```

## Ограничения

- Это демонстрационный AI-кейс, а не полноценная техническая диагностика.
- Ответ AI носит вероятностный характер и требует проверки на практике.
