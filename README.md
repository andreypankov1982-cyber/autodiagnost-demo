# AutoDiag AI PRO

Демо-проект AI-сервиса для первичной диагностики автомобиля по симптомам и кодам ошибок OBD-II.

Приложение собирает данные об автомобиле, отправляет их на backend, после чего AI формирует структурированный диагностический отчёт: вероятные причины неисправности, что проверить в первую очередь и какие шаги предпринять дальше.

## О проекте

AutoDiag AI PRO — это демонстрационный full-stack проект, который показывает, как можно объединить:

- веб-интерфейс для ввода данных
- backend на Node.js / Express
- валидацию входящих данных
- интеграцию с OpenAI API
- генерацию диагностического отчёта
- экспорт результата в PDF

Пользователь указывает:

- марку автомобиля
- модель
- год выпуска
- тип двигателя
- тип трансмиссии
- симптомы неисправности
- коды ошибок OBD-II

После этого система отправляет запрос в AI и возвращает понятный структурированный ответ.

## Возможности

## Как запустить локально

### 1. Установить зависимости

    npm install

### 2. Создать файл .env

В корне проекта создай файл `.env` со следующим содержимым:

    OPENAI_API_KEY=your_openai_api_key
    PORT=3000

### 3. Запустить backend

    npm start

После запуска сервер будет доступен по адресу:

    http://localhost:3000

### 4. Открыть frontend

Открой файл `index.html` в браузере  
или запусти его через Live Server в VS Code / Cursor.

## API

### GET /health

Проверка, что backend работает.

Пример ответа:

    { "ok": true }

### POST /api/diagnose

Генерация AI-диагностики автомобиля.

Пример тела запроса:

    {
      "brand": "Toyota",
      "model": "Camry",
      "year": 2018,
      "engine": "Бензин",
      "trans": "АКПП",
      "symptoms": "Плавают обороты, вибрация на холостом ходу",
      "errors": "P0171, P0420"
    }

Пример ответа:

    {
      "success": true,
      "diagnosis": "..."
    }

## Важно

- Проект является демонстрационным кейсом и не заменяет полноценную техническую диагностику автомобиля.
- Ответ AI носит вероятностный характер и требует проверки на практике.
- Цель проекта — показать интеграцию интерфейса, backend-логики, валидации данных и AI-генерации ответа в одном рабочем решении.
