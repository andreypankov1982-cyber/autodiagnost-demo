# AutoDiag AI PRO

Демо full-stack проекта AI-сервиса для первичной диагностики автомобиля по симптомам и кодам ошибок OBD-II.

Проект показывает, как можно объединить удобный веб-интерфейс, backend на Node.js / Express, валидацию входных данных, интеграцию с OpenAI API и генерацию структурированного диагностического ответа в одном рабочем решении.

## О проекте

AutoDiag AI PRO — это демонстрационный AI-инструмент, который помогает сформировать предварительное диагностическое заключение по данным автомобиля.

Пользователь указывает:
- марку автомобиля
- модель
- год выпуска
- тип двигателя
- тип трансмиссии
- симптомы неисправности
- коды ошибок OBD-II

После отправки формы frontend передаёт данные на backend, где они проходят валидацию. Затем backend отправляет запрос в OpenAI API, получает ответ и возвращает пользователю структурированный диагностический отчёт.

Результат содержит:
- краткий итог
- наиболее вероятные причины неисправности
- что проверить для подтверждения
- рекомендуемый план действий

Дополнительно результат можно сохранить в PDF.

## Как запустить локально

### 1. Установить зависимости

Перейди в папку backend и установи зависимости:

    cd backend
    npm install

### 2. Создать файл .env

В папке backend создай файл `.env` со следующим содержимым:

    OPENAI_API_KEY=your_openai_api_key
    PORT=3000

### 3. Запустить backend

    npm start

После запуска сервер будет доступен по адресу:

    http://localhost:3000

### 4. Открыть frontend

Открой файл `index.html` в браузере  
или запусти его через Live Server в VS Code / Cursor.

## API

### GET /health

Проверка, что backend работает.

Пример ответа:

    { "ok": true }

### POST /api/diagnose

Генерация AI-диагностики автомобиля.

Пример тела запроса:

    {
      "brand": "Toyota",
      "model": "Camry",
      "year": 2018,
      "engine": "Бензин",
      "trans": "АКПП",
      "symptoms": "Плавают обороты, вибрация на холостом ходу",
      "errors": "P0171, P0420"
    }

Пример ответа:

    {
      "success": true,
      "diagnosis": "..."
    }

## Важно

- Проект является демонстрационным кейсом и не заменяет полноценную техническую диагностику автомобиля.
- Ответ AI носит вероятностный характер и требует практической проверки.
- Основная цель проекта — показать рабочую интеграцию интерфейса, backend-логики и AI-генерации ответа.
